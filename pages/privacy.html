BTube Privacy Policy

BTube creator-first aur privacy-by-design architecture par aadharit hai. Hum aapke viewing habits aur personal files ka poora aadar karte hain aur unhe surrender nahi karte.

Last updated: October 2026 • Version 2.4

Local Device Storage Architecture

BTube par aapka profile aur channel setup aapke phone ke browser ki secure HTML5 LocalStorage me hi surakshit rehta hai:

Profile DP & Banner Aapke local storage me compress hokar rahti hai, third-party server par upload nahi hoti.
Custom Playlists Aapki banayi hui playlists aur save kiye huye gaane aapke device me private rehte hain.
Offline Downloads Downloads phone ke offline browser cache me save hote hain bina external internet leak ke.
Time Watched Stats Daily watch minutes aur weekly bar chart calculate hokar aapke device par hi render hota hai.

No Ad-Tracking or Data Selling

Hum kisi bhi third-party data broker ya marketing company ko aapka data monitor ya sell nahi karte:

Zero Cross-App Tracking BTube app ke bahar aap kis website ya application ko use karte hain, hum use track nahi karte.
No Location Snooping Background GPS ya precise location permissions ki koi zaroorat nahi hoti.

Your Rights & Complete Data Control

Aap apne poore record ko Settings aur History menu se bina kisi rukawat ke manage aur delete kar sakte hain:

Clear Watch & Search History History page ke 3-dots menu se ek tap me saari watch history clear ki ja sakti hai.
Purge Offline Downloads Downloads page se offline storage bar ke zariye aap sabhi videos ko kisi bhi waqt delete kar sakte hain.
Reset Channel Settings Browser cookies ya cache clear karne se local profile data fresh start ho jata hai.

Platform Security Standards

BTube SSL/TLS Encryption ke sath GitHub Pages aur PWA sandbox environment me run karta hai, jisse cross-site script injections aur unauthorized tampering rokhi jaati hai.
